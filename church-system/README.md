# 🏛️ Tekle Sawiros Sunday School — Web Frontend

The Next.js client application for the Tekle Sawiros Sunday School Management and Distance Education LMS.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
